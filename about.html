Library architecture

A smarter reading interface.

NovaLib turns a classic catalog into a polished virtual experience with responsive layouts, live media, saved collections, and fast discovery.

The experience

The project uses real video backgrounds, layered glass panels, animated reveals, localStorage sessions, and dynamic JavaScript rendering while staying within HTML, CSS, and JavaScript.

Why it works

The interface keeps the main reading actions close: browse, inspect details, save favourites, and return later without a complicated setup. The design uses clear sections so students can present the project confidently.
