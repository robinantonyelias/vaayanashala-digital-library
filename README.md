# Vaayanashala – Digital Library Interface

## Project Description

Vaayanashala is a responsive digital library website developed to provide users with an engaging and user-friendly online reading experience. The platform enables users to browse books, access detailed book information, read PDF content, manage favourite books, explore membership plans, and navigate through a modern digital library environment.

The project focuses on combining clean visual design, responsive layouts, interactive user features, and smooth navigation to create a complete digital library solution.

## Features

* Hero video background
* Responsive user interface
* Book catalog and browsing experience
* Detailed book information pages
* PDF reading support
* Login and signup interface
* Membership plans
* Favourite books management
* User session handling using Local Storage
* About page
* Contact page with form validation
* AOS scroll animations
* Glassmorphism-inspired user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* AOS (Animate On Scroll)
* Local Storage
* GitHub Pages
